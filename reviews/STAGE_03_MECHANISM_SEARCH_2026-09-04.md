## 1. Executive mechanism-search verdict

**Canonical verdict: `GO` -> `GO TO MINIMAL MODEL`.**

The preferred minimal mechanism is:

> **Coalition-scope implementation response:** a formal standards coalition changes the number/scope of rival products to which a firm's interoperability implementation applies. A wider formal coalition increases the reach/network value of implementation but also changes the product-market rent loss from stronger effective competition. Because firms choose implementation for profit while governments evaluate national welfare, the resulting regime-specific implementation equilibrium can change a government's coalition participation/deviation ranking.

The preferred theorem target remains **implementation-induced stability reversal**:

`sign Delta_i^endo(rho,rho';theta) != sign Delta_i^benchmark(rho,rho';theta)`

on a nonempty parameter region.

The key reason to select this mechanism is minimality. The same implementation technology and the same downstream primitives operate under every formal regime. The formal regime changes only the *scope/set of interoperability links*. The desired result is therefore not obtained by assigning unrelated technologies, costs, or policy instruments to different regimes.

No Stage-2 killed ingredient is revived as a contribution claim.

## 4. Candidate-by-candidate mechanism audit

### C1 — Coalition-scope network/reach vs competition exposure — SELECTED

**One-sentence logic.** Formal coalition size changes how many products/users are reached by one firm's implementation; this raises interoperability/network value but also changes the product-market competitive exposure generated by that implementation.

**Feedback loop.**

`rho -> partner scope s_i(rho) -> private marginal return to a_i -> a*(rho) -> Cournot/Bertrand outcomes -> national welfare -> government deviation payoff`.

**Endogenous margin.** Firm implementation intensity `a_i in [0,1]`.

**Minimum players/timing.** Three countries, one firm each; government partition; implementation; product competition; national welfare; deviation from grand coalition to a two-country coalition plus singleton.

**Minimum new interaction.** The same `a_i` affects more interoperability links when the formal coalition is larger. No new policy instrument is needed.

**Prior-art threat.** B1 compatibility models already contain network-benefit/competition trade-offs; van Wegberg (2004) studies multi-market scope and compatibility; B4 contains coalition-size/network/competition effects. None audited in Stage 2 makes government coalition stability depend on a separate post-coalition continuous implementation equilibrium.

**Expected theorem.** Coalition enlargement can lower rather than raise private implementation when competition exposure grows faster than private reach benefits; this response can reverse the sign of government stability relative to fixed/full implementation.

**Welfare content.** Firms internalize profit; governments add domestic consumer surplus, so implementation changes national incidence as well as profits.

**Institutional interpretation.** A common technical standard can enlarge the set of products/ecosystems with which optional interface features, API support, protocol completeness, certification profiles, or cross-system functions interoperate. Vendors still decide implementation completeness.

**Tractability risk.** Moderate. Need a three-firm differentiated product market and regime-specific implementation game. Do not add topology/dynamics.

**Fatal referee attack.** If the larger-coalition effect on `a*` is imposed by an arbitrary regime-specific coefficient rather than derived from the product-market subgame, the mechanism is engineered. Stage 4 must derive it from identical primitives across regimes.

**Nested benchmarks.** B0 under binary/fixed implementation; B1 when government partition is fixed; B3 when implementation is exogenous; B4 when government and firm coalition actors collapse.

**Unique full-game interaction.** Coalition scope changes private implementation incentives and the continuation response feeds back into a distinct government's membership payoff.

### C2 — Bilateral implementation public-good / free-riding — TOP 2

**Logic.** Effective interoperability requires contributions by multiple member firms, creating implementation free-riding after a formal agreement.

**Feedback.** `rho -> shared-interface contribution game -> effective interoperability -> competition/welfare -> stability`.

**Minimum new interaction.** Joint implementation aggregator such as `Phi(a_i,a_j)`.

**Prior threat.** Klimenko already emphasizes insufficient private compatibility enhancement when one firm's effort benefits both products; modern interoperability-network work adds bilateral structure.

**Expected theorem.** A formal coalition can be destabilized by implementation free-riding even when full implementation would make it stable.

**Welfare.** Strong consumer externality.

**Tractability.** Better than C1 algebraically if a simple aggregator is chosen, but choosing `min`, product, or sum creates an additional technology choice and can drive the result.

**Fatal attack.** The reversal may be an ordinary public-good underprovision result with standards vocabulary.

**Decision.** Retain only as fallback if C1 fails for structural reasons. Do not combine with C1 in Stage 4.

### C3 — National-incidence / cross-border rent-shifting — TOP 3

**Logic.** Firms maximize worldwide profit from implementation while governments value domestic consumer surplus plus home-firm worldwide profit, so the geographic incidence of compatibility rents changes national coalition incentives.

**Feedback.** `rho -> a*(rho) -> cross-border price/share changes -> domestic CS + home-firm profit -> deviation`.

**Prior threat.** Klimenko's strategic trade-policy compatibility models and Gandal–Shy already contain national-welfare/rent-shifting logic.

**Expected theorem.** Endogenous implementation can reverse which country wants to leave even when world welfare ranking is unchanged.

**Tractability.** Requires explicit national markets/asymmetry to avoid the effect cancelling under symmetry.

**Fatal attack.** The result may be a standard terms-of-trade/rent-shifting comparative static.

**Decision.** Do not use as Stage-4 core. National-welfare incidence remains part of C1's welfare accounting but is not a separate mechanism.

### C4 — Implementation economies of scope across member markets

One interoperability investment applies to several coalition markets. Coalition enlargement increases the private return to implementation.

**Reject as preferred mechanism:** B0 already has one-time adoption covering multiple markets, and van Wegberg-type multi-market compatibility models make scope effects familiar. High risk of merely smoothing B0's fixed-cost threshold.

### C5 — Formal-standard floor / private top-up crowd-out

A government agreement supplies baseline compatibility, reducing firms' incentives for additional private implementation.

**Reject:** Klimenko (2009) already places government minimum compatibility standards together with private compatibility-enhancing activity. The crowd-out logic is too close to B2 and risks being a policy-effort substitution result rather than a coalition-stability contribution.

### C6 — Continuous private bypass / selective erosion

An outsider or member continuously implements another coalition's interface, eroding formal exclusion.

**Reject:** this is the closest continuous analogue of B0's existing selective-erosion theorem. Without a qualitatively new intensive-margin result it is exactly the Stage-2 forbidden smoothing route.

### C7 — Directional / one-way interoperability

A firm can make its system compatible outward without granting reciprocal access, creating asymmetric rents and coalition incentives.

**Reject for Stage 4:** potentially interesting, but adds a directional compatibility technology and a larger strategy space before the basic continuous feedback has survived. One-way standards/translator strategies also have prior-art exposure.

### C8 — Switching/data portability

Implementation reduces switching/portability frictions, making post-agreement compatibility dynamically valuable.

**Reject:** Jeon–Menicucci–Nasr makes this a high-risk literature family and the dynamic state variable violates minimality.

### C9 — Pairwise topology/endogenous links

Firms choose weighted interoperability links inside a formal coalition.

**Reject:** directly exposed to Huang–Tan–Teh–Zhou and modern platform-interoperability work; severe complexity increase.

### C10 — Modular complement access

Implementation enlarges the set of mix-and-match components/services accessible across standards.

**Reject:** classic systems/mix-and-match compatibility literature is close, and it does not simplify the government-coalition layer enough to justify the change.

## 5. Targeted Stage-3 mini-search findings

The targeted search reinforced, rather than weakened, the ranking.

1. **van Wegberg (2004), `Compatibility Choice by Multi-market Firms`**, Information Economics and Policy 16, 235–254, already emphasizes that compatibility is double-edged — network/demand gains versus weaker differentiation/price competition — and explicitly studies multi-market scope. Therefore C1 cannot claim either ingredient. Its only permissible contribution is the government-coalition continuation feedback.
2. **Toshimitsu (2018)** already derives strategic compatibility choice under differentiated Cournot competition with network externalities and studies a stable network alliance. This raises the burden on C1/C2: the coalition player must remain a national government with a distinct objective.
3. **Klimenko (2009)** confirms the weakness of C5: government minimum compatibility regulation and firms' compatibility-enhancing activities are already jointly modeled in international competition.

No new search hit was found that reproduces C1's complete two-level government coalition / private continuous implementation / regime-specific national-stability loop. This absence is not novelty evidence; it only leaves C1 eligible for Stage 4.

## 6. Reduced-form coherence test for C1 — diagnostic only

This is **not** the Stage-4 model and not a proof. It tests whether the desired direction can arise without directly assuming a stability reversal.

Let `s` denote the number of formal interoperability partners faced by a firm. Consider the local reduced-form continuation profit approximation

`pi(a;s) = b s a - 0.5 [kappa + chi s^2] a^2`,

where:

- `b s a` is the private reach/network gain from applying implementation to `s` partners;
- `chi s^2 a^2 / 2` is the product-market rent erosion generated by increasingly broad competitive exposure;
- `kappa a^2 / 2` is ordinary engineering/implementation cost.

The private optimum is

`a*(s) = b s / [kappa + chi s^2]`.

For a two-member coalition (`s=1`) versus a three-member coalition (`s=2`):

`a*(2)-a*(1) = - b(2 chi-kappa)/[(chi+kappa)(4chi+kappa)]`.

Hence

`kappa < 2 chi  =>  a*(2) < a*(1)`.

So coalition enlargement can reduce implementation even though the potential interoperability scope is larger. The sign is generated by a trade-off, not imposed as a regime dummy.

A Python grid check also verified that, once the already-required formal-regime welfare wedge from B0/B3 is represented in reduced form, there are positive-parameter examples in which full/exogenous implementation favors the larger coalition while endogenous implementation reverses the ranking. One diagnostic example uses

`b=0.1, chi=0.1, kappa=0.1`,

which gives implementation levels `0.5` and `0.4` for one versus two partners. With an inherited formal-regime cost/restriction term of `0.1` and consumer interoperability value about `0.22564`, the exogenous-full continuation difference is approximately `+0.07564` while the endogenous difference is approximately `-0.01731`.

This only establishes **logical feasibility**. Stage 4 must derive the corresponding coefficients from a genuine product-market model. It may not insert `chi s^2` merely because it produces the result.

## 7. Preferred minimal mechanism/generalization

### Name

**Coalition-Scope Implementation Crowd-Out (CSIC)**

### Economic statement

A formal standards coalition expands the set of partners reached by interoperability implementation. The expansion raises the demand/network return to implementation, but it can also magnify the loss of product-market rents caused by making more rivals effectively compatible. Firms choose implementation based on profit, not national consumer surplus. Therefore a larger formal coalition need not induce more private implementation; the induced continuation response can change the sign of a government's coalition-deviation payoff.

### Why this is preferred

- It uses the Stage-2 surviving loop directly.
- It does not require a new government instrument.
- It does not require dynamics, topology, switching costs, or firm heterogeneity.
- It can use the same implementation technology in every regime.
- It nests B0/B1/B3 conceptually.
- It offers a sharper candidate result than `a*` being interior: **formal coalition enlargement may crowd out implementation and reverse coalition stability**.

## 8. Exact Stage-4 model skeleton

Stage 4 is authorized to test **only C1 / CSIC**.

### Players

- Three countries/governments `i=1,2,3`.
- One nationally owned firm per country.
- Consumers in three symmetric national markets; all firms sell in all markets.

### Formal regimes

Minimum comparison:

- `rho^IS = {{1,2,3}}` — international/common standards coalition;
- `rho_12^SU = {{1,2},{3}}` — country 3 deviates, leaving a two-country standards coalition.

Add `rho^SW` only if mathematically necessary for a benchmark; do not make it a third headline regime at Stage 4.

### Timing

1. Formal regime `rho` is given for the continuation game / government deviation comparison.
2. Firms simultaneously choose implementation `a_i in [0,1]`.
3. Firms compete in quantities (preferred first test: Cournot, to stay close to B0).
4. National welfare is calculated.
5. Government stability compares `rho^IS` with unilateral deviation to `rho_12^SU` using regime-specific continuation equilibria.

### Implementation interpretation

`a_i` is the completeness/intensity with which firm `i` implements the common interface available to its formal coalition. The same engineering technology applies in all regimes. A larger coalition changes the number of formally eligible interoperability partners; it does **not** change the implementation cost function by assumption.

For the first Stage-4 test, use a one-sided implementation exposure specification to isolate the scope mechanism: the user/network value of firm `i`'s product from coalition partners is scaled by `a_i`. Do not introduce a pairwise `Phi(a_i,a_j)` in the first pass. Bilateral aggregation belongs to C2 and would contaminate the mechanism test.

### Product-market primitive to test first

Use a B0-style linear Cournot network-good block in each national market. A candidate form is

`p_i^k = 1 - Q^k + v a_i sum_{j in C_i(rho), j!=i} q_j^k`,

with identical marginal production cost in the first pass.

This equation is a **Stage-4 candidate**, not a frozen result. Stage 4 must verify whether it genuinely generates the private reach-versus-competition trade-off. If it makes implementation monotonically profitable and requires artificial curvature to rescue the result, return NO-GO or reconsider C1 within Stage-4 rules; do not add a second mechanism.

### Implementation cost

First test: `C(a_i)=kappa a_i^2/2`, interpreted as engineering, conformance testing, maintenance, and support effort.

This term is allowed as a technology cost, not as novelty and not as a license to force interiority. If a quadratic cost only manufactures a stationary point that fails global optimization, Stage 4 fails.

### Firm objective

`Pi_i(rho,a,q) = sum_k pi_i^k - C(a_i)`.

### Government objective

`W_i(rho)=CS_i(rho)+Pi_i(rho)`.

Do not include foreign-firm profits in country `i` welfare.

### Stability object

`Delta_3^endo = W_3(rho^IS; a*(rho^IS)) - W_3(rho_12^SU; a*(rho_12^SU))`.

Symmetry can then cover other unilateral deviations.

### Benchmark stability object

At minimum compare against fixed/full implementation:

`Delta_3^full = W_3(rho^IS; a=1) - W_3(rho_12^SU; benchmark implementation)`.

Also recover a binary/fixed implementation benchmark close to B0 if the mapping is clean.

## 9. Nested benchmark skeletons

### B0 recovery

Restrict private implementation to the relevant binary/fixed set and recover the government-partition -> private compatibility/adoption -> Cournot -> national welfare -> stability logic. Exact algebra need not reproduce every B0 cost block if Stage 4 uses a stripped minimal version, but the difference must be explicit.

### B1 recovery

Fix `rho`. The remaining game is ordinary continuous private compatibility/implementation followed by product competition. No claim from this subgame is novel.

### B3 recovery

Fix implementation exogenously at full/regulated compatibility. Government compares formal standardization regimes without a private intensive-margin continuation response.

### B4 contrast

Collapse governments and firms into one profit-maximizing coalition actor and remove national consumer surplus. The distinct two-level feedback disappears.

## 10. Stage-4 candidate propositions / kill tests

Stage 4 must attack, in this order:

### P1 — Well-defined private implementation equilibrium

For each relevant `rho`, establish existence and characterize `a*(rho)` with FOC/KKT, SOC/concavity or global best-response checks, asymmetric deviations, and corners.

### P2 — Regime dependence

Show that `a*(rho^IS)` and `a*(rho^SU)` are genuinely different because coalition scope changes the product-market marginal return to implementation, not because a regime-specific cost coefficient was inserted.

### P3 — Coalition-scope crowd-out

Find a nonempty parameter region with a sharp result such as

`a_IS* < a_SU*`

for the relevant symmetric member implementation statistic, despite the larger formal interoperability scope under IS.

If only `a_IS* >= a_SU*` obtains monotonically, C1 may still survive only if P4 produces a nontrivial stability reversal for another reason already inherent in the same mechanism. Do not add C2/C3.

### P4 — Implementation-induced stability reversal — HEADLINE KILL TEST

Find a nonempty parameter region with

`sign Delta_3^endo != sign Delta_3^full`

or the corresponding binary benchmark.

### P5 — Benchmark nonredundancy

Show that the P4 sign reversal is not obtainable by simply changing one B0 fixed-cost threshold or reparameterizing a known compatibility coefficient.

### Stronger optional result

A non-monotone/disconnected stability region in `v`, `kappa`, or a primitive differentiation/competition parameter, only if it emerges from the same minimal model. Do not add primitives to obtain it.

## 11. Why rejected candidates must not leak into Stage 4

- No bilateral `Phi(a_i,a_j)` or weakest-link technology: that is C2.
- No trade taxes, asymmetric national policy instruments, or market-size asymmetry: that is C3/B2 territory.
- No coalition-dependent implementation cost: that would convert C1 into C4/C5.
- No private outsider bypass margin: that revives C6/B0 smoothing.
- No directional link matrix, switching state, installed base, or topology: C7–C9.

If C1 fails, Stage 4 should report failure. The project may then return to Stage 3 and consider C2 as a separate branch, not silently hybridize mechanisms.

## 12. Final verdict and next-stage contract

**Verdict: `GO` -> `GO TO MINIMAL MODEL`.**

**Stage-4 contract:** test only Coalition-Scope Implementation Crowd-Out using the three-country IS-versus-SU skeleton above. The first objective is not to prove a publishable theorem but to determine whether identical primitives across regimes can generate a verified regime-dependent private implementation equilibrium and an implementation-induced coalition-stability reversal.

Return `NO-GO` for this mechanism if:

1. implementation is generically corner-valued unless curvature is engineered;
2. the private response is only a monotone scale effect with no stability reversal;
3. the stability change is algebraically equivalent to smoothing B0's threshold;
4. the product-market block makes the supposed competition-exposure term an assumed coefficient rather than a derived effect;
5. the model requires importing C2/C3 or another rejected mechanism to work.
